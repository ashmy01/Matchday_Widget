Add it to your iPhone

      
A website can't place a widget on your phone by itself — every phone needs a tiny "host" app for the widget to live in. We use Scriptable, which is free and lightweight.

      
    
        
  1. Install Scriptable from the App Store (free).
    2. 
        
  2. Open Scriptable, tap + to create a new script.
    3. 
        
  3. Delete any sample text, then paste your setup text from above.
    4. 
        
  4. Tap the script's name at the top, rename it “World Cup”, and tap Done.
    5. 
        
  5. Go to your home or lock screen, long-press, tap +, search Scriptable, and add a widget. Pick the Large size if you want to see all of the day's matches at once.
    6. 
        
  6. Long-press the new widget → Edit Widget → choose the World Cup script.
    7. 
      

      

        Why can't I scroll the widget? iPhone widgets are static — Apple doesn't allow scrolling inside any home/lock-screen widget. To see more matches, use the Large widget size (it fits a whole day); the Medium size shows the next three with a “+ more” note.
      

      

        Heads up: phones refresh widgets on their own schedule (roughly every 15 min–1 hr, less often overnight), so it advances to the next match with a short lag — think “what's on / what's next” board, not a live stopwatch. If you delete Scriptable, the widget goes with it.
      

      
Android support is coming next — the same approach works with a free host app there too.
